# 1. What is CSS Grid?

CSS Grid is a **2-dimensional layout system** used to arrange elements in **rows and columns**.

It helps us create responsive web page layouts easily.

### Advantages

- Creates rows and columns
- Easy page layout
- Better alignment
- Less CSS code
- Responsive design

---

# 2. Grid Terminology

```
Grid Container
+---------------------------+
| 1 | 2 | 3 |
|-----------|
| 4 | 5 | 6 |
+---------------------------+
```

### Grid Container

Parent element.

```css
.container{
    display:grid;
}
```

---

### Grid Item

Direct children of the grid container.

```html
<div class="container">

    <div>1</div>
    <div>2</div>
    <div>3</div>

</div>
```

Here

```
1
2
3
```

are Grid Items.

---

### Grid Lines

```
Line1   Line2   Line3   Line4

|--------|--------|--------|
```

Items are placed using **Grid Lines**.

---

### Grid Cell

One single box inside the grid.

```
+------+
| Cell |
+------+
```

---

# 3. display:grid

Creates a Grid Container.

### Syntax

```css
display:grid;
```

### HTML

```html
<div class="container">

    <div>1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>

</div>
```

### CSS

```css
.container{

display:grid;

grid-template-columns:100px 100px;

}

.container div{

border:1px solid black;
padding:20px;
text-align:center;

}
```

### Output

```
+-------+-------+
|   1   |   2   |
+-------+-------+
|   3   |   4   |
+-------+-------+
```

### Explanation

- Parent becomes Grid Container.
- Child elements become Grid Items.
- CSS automatically places items.

---

# 4. display:inline-grid

Works like `display:grid`, but behaves as an **inline element**.

### Syntax

```css
display:inline-grid;
```

### Difference

| display:grid | display:inline-grid |
|--------------|---------------------|
| Block element | Inline element |
| Takes full width | Takes required width |

---

# 5. grid-template-columns

Creates columns.

## Syntax

```css
grid-template-columns:auto auto auto;
```

OR

```css
grid-template-columns:100px 200px auto;
```

---

## Example 1

### HTML

```html
<div class="container">

<div>1</div>
<div>2</div>
<div>3</div>
<div>4</div>

</div>
```

### CSS

```css
.container{

display:grid;

grid-template-columns:100px 100px;

gap:10px;

}

.container div{

background:lightblue;
border:1px solid black;
padding:20px;
text-align:center;

}
```

### Output

```
+---------+---------+
|    1    |    2    |
+---------+---------+
|    3    |    4    |
+---------+---------+
```

### Explanation

Two values

↓

Two Columns

↓

Items fill left to right.

↓

Remaining items automatically move to the next row.

---

## Example 2 (auto)

```css
grid-template-columns:auto auto auto;
```

Suppose container width is **900px**

```
900px

↓

auto auto auto

↓

300px 300px 300px
```

Output

```
+-----------+-----------+-----------+
|     1     |     2     |     3     |
+-----------+-----------+-----------+
```

---

## Example 3 (Mixed Width)

```css
grid-template-columns:100px auto 200px;
```

Container Width = **900px**

```
100px + auto + 200px

↓

Remaining Width

900 - 100 - 200

↓

600px
```

Output

```
+--------+----------------------+--------+
|100px   |       600px          |200px   |
+--------+----------------------+--------+
```

### Remember

```
Number of Values

=

Number of Columns
```

Examples

```
auto auto

↓

2 Columns
```

```
auto auto auto auto

↓

4 Columns
```

# 6. grid-template-rows

Creates row heights.

### Syntax

```css
grid-template-rows:100px 200px;
```

### HTML

```html
<div class="container">

<div>1</div>
<div>2</div>
<div>3</div>
<div>4</div>

</div>
```

### CSS

```css
.container{

display:grid;

grid-template-columns:150px 150px;

grid-template-rows:100px 200px;

gap:10px;

}

.container div{

border:1px solid black;

display:flex;
justify-content:center;
align-items:center;

}
```

### Output

```
+-----------+-----------+
|     1     |     2     | 100px
+-----------+-----------+

|     3     |     4     | 200px
|           |           |
+-----------+-----------+
```

### Explanation

- First row height = 100px
- Second row height = 200px

# 7. gap

Adds space between rows and columns.

### Syntax

```css
gap:20px;
```

Without Gap

```
+---+---+---+
|1  |2  |3  |
+---+---+---+
|4  |5  |6  |
+---+---+---+
```

With Gap

```
+---+    +---+    +---+
|1  |    |2  |    |3  |
+---+    +---+    +---+

      20px

+---+    +---+    +---+
|4  |    |5  |    |6  |
+---+    +---+    +---+
```

### Syntax

```css
gap:20px 50px;
```

Meaning

```
20px → Row Gap

50px → Column Gap
```

---

### Output

```
+---+---+---+
|1  |2  |3  |
+---+---+---+

     30px

+---+---+---+
|4  |5  |6  |
+---+---+---+
```

### Explanation

Only the rows have spacing.

# 10. Understanding Grid Lines

Grid Lines are **imaginary lines** used to place Grid Items.

Suppose

```css
grid-template-columns:auto auto auto;
```

Grid becomes

```
        Line1   Line2   Line3   Line4

          |       |       |       |

+----------+-------+-------+
|          |       |       |
+----------+-------+-------+
```

Notice

```
3 Columns

↓

4 Grid Lines
```

Always remember

```
Number of Grid Lines

=

Number of Columns + 1
```

# 11. grid-column

Used to make an item occupy multiple columns.

### Long Form

```css
.item1{

grid-column-start:1;

grid-column-end:3;

}
```

### Shorthand

```css
.item1{

grid-column:1/3;

}
```

Meaning

```
Start at Line 1

↓

End at Line 3

↓

Occupies Column 1 and Column 2
```

---

## Example

### HTML + CSS

```<!DOCTYPE html>
<html>
<head>
<style>
.container{
    display: grid;
    grid-template-columns: 100px 100px 100px;
    gap: 10px;
}

.item1{
    background: red;
    padding: 20px;
    grid-column: 1/3;
}

.container div{
    background: lightblue;
    padding: 20px;
    text-align: center;
    border: 1px solid black;
}
</style>
</head>

<body>

<div class="container">
    <div class="item1">1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>
    <div>5</div>
    <div>6</div>
</div>

</body>
</html>
```

### Normal Layout

```
+---+---+---+
|1  |2  |3  |
+---+---+---+
|4  |5  |6  |
+---+---+---+
```

### Output

```
+-----------+-------+
|     1     |   2   |
+-----------+-------+
|  3  |  4  |  5    |
+-----+-----+-------+
|  6                |
+-------------------+
```

### Explanation

```
grid-column:1/3;

↓

Starts at Line 1

↓

Ends at Line 3

↓

Occupies 2 Columns
```
