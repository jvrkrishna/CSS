# What is CSS Transition?

A **CSS Transition** allows an element to **change from one style to another smoothly** over a specified period of time.

Without a transition, changes happen **instantly**.

With a transition, changes happen **gradually**.

### Example

Without Transition

```text
Width: 100px → 300px (Immediately)
```

With Transition

```text
Width: 100px
     ↓
150px
     ↓
200px
     ↓
250px
     ↓
300px
```

---

# Transition Properties

CSS provides the following transition properties:

* `transition`
* `transition-property`
* `transition-duration`
* `transition-delay`
* `transition-timing-function`

---

# 1. transition

## Definition

The **transition** property is a shorthand property used to specify transition settings in one line.

### Syntax

```css
transition: property duration timing-function delay;
```

### Example

```css
transition: width 2s;
```

This means:

* Transition Property → width
* Duration → 2 seconds

---

# Example 1 : Basic Transition

## HTML

```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:100px;
height:100px;

background:red;

transition:width 2s;

}

div:hover{

width:300px;

}

</style>

</head>

<body>

<h2>Transition Property</h2>

<p>Move the mouse over the box.</p>

<div></div>

</body>
</html>
```

### Output

Before Hover

```text
+---------+
|         |
|   Red   |
| 100px   |
+---------+
```

After Hover

```text
100px
   ↓
150px
   ↓
200px
   ↓
250px
   ↓
300px
```

The width changes smoothly in **2 seconds**.

# 2. transition-property

## Definition

Specifies which CSS property should have the transition effect.

### Syntax

```css
transition-property:width;
```

### Example

```css
div{

transition-property:width;

transition-duration:2s;

}
```

Only the **width** property will animate.

---

# Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:100px;
height:100px;

background:red;

transition-property:width;

transition-duration:2s;

}

div:hover{

width:300px;

background:blue;

}

</style>

</head>

<body>

<div></div>

</body>
</html>
```

### Output

* Width changes smoothly.
* Background color changes immediately because it is **not included** in `transition-property`.

# 5. transition-timing-function

## Definition

Specifies the speed curve of the transition.

### Syntax

```css
transition-timing-function:value;
```

### Values

| Value       | Description                                 |
| ----------- | ------------------------------------------- |
| ease        | Slow start, fast middle, slow end (Default) |
| linear      | Same speed from start to end                |
| ease-in     | Slow start                                  |
| ease-out    | Slow end                                    |
| ease-in-out | Slow start and slow end                     |

---

# Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:100px;

height:60px;

background:red;

transition:width 3s;

}

#box1{

transition-timing-function:linear;

}

#box2{

transition-timing-function:ease;

}

#box3{

transition-timing-function:ease-in;

}

#box4{

transition-timing-function:ease-out;

}

#box5{

transition-timing-function:ease-in-out;

}

div:hover{

width:300px;

}

</style>

</head>

<body>

<div id="box1">Linear</div><br>

<div id="box2">Ease</div><br>

<div id="box3">Ease-In</div><br>

<div id="box4">Ease-Out</div><br>

<div id="box5">Ease-In-Out</div>

</body>
</html>
```

### Output

* **Linear** → Constant speed.
* **Ease** → Slow → Fast → Slow.
* **Ease-In** → Slow start.
* **Ease-Out** → Slow end.
* **Ease-In-Out** → Slow start and slow end.

# Transition Shorthand Order

```css
transition:

property

duration

timing-function

delay;
```

### Example

```css
transition:width 2s ease 1s;
```

Equivalent to

```css
transition-property:width;

transition-duration:2s;

transition-timing-function:ease;

transition-delay:1s;
```

# Transition Properties Summary

| Property                   | Purpose               | Example                |
| -------------------------- | --------------------- | ---------------------- |
| transition                 | Shorthand property    | `transition:width 2s;` |
| transition-property        | Property to animate   | `width`                |
| transition-duration        | Transition time       | `2s`                   |
| transition-delay           | Delay before starting | `2s`                   |
| transition-timing-function | Speed curve           | `ease`, `linear`       |

---

# Transition vs Animation

| Transition                                 | Animation                               |
| ------------------------------------------ | --------------------------------------- |
| Triggered by an event (hover, focus, etc.) | Can start automatically                 |
| Requires a property change                 | Uses `@keyframes`                       |
| Simple effects                             | Complex multi-step effects              |
| Usually one start and one end state        | Multiple keyframes (0%, 25%, 50%, etc.) |

# Frequently Asked Interview Questions

### 1. What is CSS Transition?

CSS Transition is used to change CSS property values smoothly over a specified duration.

---

### 2. What is the difference between Transition and Animation?

* **Transition** needs a property change (such as `:hover`).
* **Animation** can run automatically and uses `@keyframes`.

---

### 3. What is `transition-property`?

It specifies which CSS property should be animated.

---

### 4. What is `transition-duration`?

It specifies how long the transition takes.

---

### 5. What is `transition-delay`?

It specifies how long to wait before the transition begins.

---

### 6. What is `transition-timing-function`?

It specifies the speed curve of the transition.

---

### 7. Can multiple properties be transitioned?

Yes.

Example:

```css
transition: width 2s, height 3s, background 2s;
```

---

### 8. Can transitions work with transform?

Yes.

Example:

```css
transition: transform 2s;
```

---

### 9. What is the shorthand syntax for transition?

```css
transition: property duration timing-function delay;
```

---

### 10. What is the default timing function?

```css
ease
```

---

# Quick Revision

* `transition` → Shorthand property.
