# What are CSS Media Queries?

A **CSS Media Query** is used to apply different CSS styles based on the **screen size**, **device type**, or **device characteristics**.

Media Queries help create **Responsive Web Design (RWD)**, so websites look good on desktops, laptops, tablets, and mobile phones.

---

# Why Use Media Queries?

Media Queries are used to:

* Create responsive websites.
* Change layouts for different screen sizes.
* Improve user experience on mobile devices.
* Apply different styles for portrait and landscape modes.

---

# What Can Media Queries Check?

Media Queries can check:

* Width of the viewport
* Height of the viewport
* Device orientation (Portrait or Landscape)
* Screen resolution
* Device type

---

# Basic Syntax

```css
@media media-type and (condition){

    CSS Code

}
```

### Example

```css
@media screen and (max-width:600px){

body{

background:red;

}

}
```

---

# Media Types

| Media Type | Description                             |
| ---------- | --------------------------------------- |
| all        | All media devices (Default)             |
| screen     | Computer, Laptop, Tablet, Mobile Screen |
| print      | Printer                                 |
| speech     | Screen Readers                          |

| max-height  | Maximum screen height |

---

# 1. min-width

## Definition

Applies styles when the screen width is **greater than or equal to** the specified value.

### Syntax

```css
@media screen and (min-width:600px){

}
```

---

## Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

body{

background:red;
text-align:center;
padding:100px;
font-size:30px;
color:white;

}

@media screen and (min-width:600px){

body{

background:green;

}

}

</style>

</head>

<body>

<h2>Minimum Width Example</h2>

<p>Resize the browser window.</p>

</body>
</html>
```

### Output

```text
Width < 600px

Background → Red

-----------------------

Width ≥ 600px

Background → Green
```

---

# 3. min-width and max-width Together

## Definition

Applies styles only within a specified screen width range.

### Syntax

```css
@media screen and (min-width:300px) and (max-width:500px){

}
```

---

## Example (Your Program)

```html
<!DOCTYPE html>
<html>
<head>

<style>

body{

background:red;

margin:0;

padding:170px;

text-align:center;

font-size:30px;

font-weight:bold;

color:white;

}

@media screen and (min-width:300px) and (max-width:500px){

body{

background:green;

}

}

</style>

</head>

<body>

<h2>Rama Krishna</h2>

</body>
</html>
```

### Output

```text
300px – 500px

Background → Green

-----------------------

Other Screen Sizes

Background → Red
```

---

# 4. orientation

## Definition

Checks whether the device is in **Portrait** or **Landscape** mode.

### Values

* portrait
* landscape

---

## Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

body{

background:skyblue;

text-align:center;

padding:100px;

}

@media (orientation:landscape){

body{

background:green;

color:white;

}

}

</style>

</head>

<body>

<h2>Orientation Example</h2>

<p>Rotate your mobile device.</p>

</body>
</html>
```

### Output

```text
Portrait Mode

Background → Sky Blue

-------------------------

Landscape Mode

Background → Green
```

---

# 5. Multiple Media Queries

Different CSS can be applied for different devices.

```css
@media screen and (max-width:600px){

body{

background:red;

}

}

@media screen and (min-width:601px) and (max-width:900px){

body{

background:blue;

}

}

@media screen and (min-width:901px){

body{

background:green;

}

}
```

### Output

```text
Mobile

↓

Red

Tablet

↓

Blue

Desktop

↓

Green
```

# Responsive Navigation Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

ul{

display:flex;

list-style:none;

background:black;

padding:15px;

}

li{

color:white;

padding:15px;

}

@media screen and (max-width:600px){

ul{

flex-direction:column;

}

}

</style>

</head>

<body>

<ul>

<li>Home</li>

<li>About</li>

<li>Services</li>

<li>Contact</li>

</ul>

</body>
</html>
```

### Output

Desktop

```text
Home  About  Services  Contact
```

Mobile

```text
Home

About

Services

Contact
```

# Responsive Grid Example

3

# Frequently Asked Interview Questions

### 1. What is a Media Query?

A Media Query is used to apply different CSS styles based on the device or screen size.

---

### 2. Why are Media Queries used?

They help create responsive websites that work well on mobiles, tablets, laptops, and desktops.

---

### 3. What is `@media`?

`@media` is a CSS rule used to define conditional styles.

Example:

```css
@media screen and (max-width:600px){

body{

background:red;

}

}
```

---

### 4. Difference between `min-width` and `max-width`?

* `min-width` → Applies styles when the screen width is **greater than or equal to** the specified value.
* `max-width` → Applies styles when the screen width is **less than or equal to** the specified value.

---

### 5. What is the `orientation` media feature?

It detects whether the screen is in **portrait** or **landscape** mode.

---

### 6. What media types are commonly used?

* `all`
* `screen`
* `print`
* `speech`

---

### 7. Can multiple media queries be used?

Yes. You can define different styles for different screen sizes.

---

### 8. What is Responsive Web Design (RWD)?

Responsive Web Design is a technique that makes a website adapt to different screen sizes and devices.

---

### 9. Which devices commonly use Media Queries?

* Desktop
* Laptop
* Tablet
* Mobile Phone

---

### 10. What are breakpoints?

Breakpoints are screen widths where the layout changes to provide a better user experience.
