## What is CSS Animation?
CSS Animation allows an HTML element to change its style gradually over time **without using JavaScript**.

Animation works in **2 steps**:
1. Create an animation using **`@keyframes`**
2. Apply the animation using animation properties.

# 1. @keyframes
## Definition
The `@keyframes` rule defines the different stages (frames) of an animation.

### Syntax
```css
@keyframes animationName {
    from {
        /* Starting Style */
    }

    to {
        /* Ending Style */
    }
}
```

OR
```css
@keyframes animationName {
    0% {}
    25% {}
    50% {}
    75% {}
    100% {}
}
```

## Example 1 – Using from and to
### HTML
```html
<!DOCTYPE html>
<html>
<head>
<style>
p{
    background:red;
    color:white;
    width:250px;
    text-align:center;
    padding:15px;
    font-weight:bold;

    animation-name:example;
    animation-duration:5s;
}

@keyframes example{
from{
    background:green;
    color:white;
}

to{
    background:yellow;
    color:blue;
}

}

</style>
</head>
<body>
<p>HIE TECH SOLUTIONS</p>
</body>
</html>
```

### Output
* Starts with **Green Background**
* Ends with **Yellow Background**

# 2. animation-name
## Definition
Specifies which animation (`@keyframes`) should be applied.

### Syntax
```css
animation-name: example;
```

### HTML Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

p{

background:red;
padding:15px;
width:250px;
text-align:center;

animation-name:example;
animation-duration:5s;

}

@keyframes example{

from{
background:red;
}

to{
background:blue;
color:white;
}

}

</style>

</head>

<body>

<p>Animation Name Example</p>

</body>
</html>
```

### Output

```
Red Box
      ↓
Blue Box
```

# 3. animation-duration
## Definition
Specifies how long one animation cycle takes.

### Syntax
```css
animation-duration:5s;
```

or
```css
animation-duration:500ms;
```

### HTML Example
```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:150px;
height:150px;
background:red;

animation-name:move;
animation-duration:4s;

}

@keyframes move{

from{
background:red;
}

to{
background:green;
}

}

</style>

</head>

<body>

<div></div>

</body>
</html>
```

### Output

```
Red Box
↓

Green Box (after 4 seconds)
```

---

# 4. animation-delay
## Definition
Specifies how long the animation waits before starting.

### Syntax
```css
animation-delay:2s;
```

## Positive Delay Example
### HTML
```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:120px;
height:120px;
background:red;
position:relative;

animation:move 5s;
animation-delay:2s;

}

@keyframes move{

from{
left:0;
}

to{
left:250px;
background:green;
}

}

</style>
</head>
<body>
<div></div>
</body>
</html>
```

### Output
```
Wait 2 Seconds
⬛
↓
Moves Right
```

## Negative Delay Example
```css
animation-delay:-2s;
```

### Output
Animation starts immediately as if it has already been running for **2 seconds**.

# 6. animation-direction

## Definition

Controls the direction of animation.

### Values

| Value             | Description           |
| ----------------- | --------------------- |
| normal            | Forward (Default)     |
| reverse           | Backward              |
| alternate         | Forward then Backward |
| alternate-reverse | Backward then Forward |

---

## HTML Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:100px;
height:100px;
background:red;
position:relative;

animation:move 3s infinite alternate;

}

@keyframes move{

from{
left:0;
}

to{
left:300px;
background:blue;
}

}

</style>

</head>

<body>

<div></div>

</body>
</html>
```

### Output

```
⬛ -------->

<-------- ⬛

Repeats Forever
```

# 7. animation-timing-function

## Definition

Controls the speed of the animation.

### Values

* ease
* linear
* ease-in
* ease-out
* ease-in-out
* cubic-bezier()

---

## HTML Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:120px;
height:60px;
background:red;
position:relative;

animation:move 5s infinite;

}

#box1{

animation-timing-function:linear;

}

@keyframes move{

from{
left:0;
}

to{
left:300px;
}

}

</style>

</head>

<body>

<div id="box1"></div>

</body>
</html>
```

### Output

```
Moves at Constant Speed
```

# 9. animation (Shorthand Property)

Instead of writing multiple properties separately, write them in one line.

### Syntax

```css
animation:
name
duration
timing-function
delay
iteration-count
direction
fill-mode;
```

### Example

```css
animation:move 5s linear 2s infinite alternate forwards;
```

Equivalent to

```css
animation-name:move;
animation-duration:5s;
animation-timing-function:linear;
animation-delay:2s;
animation-iteration-count:infinite;
animation-direction:alternate;
animation-fill-mode:forwards;
```

# Complete Animation Example

```html
<!DOCTYPE html>
<html>
<head>

<style>

div{

width:100px;
height:100px;
background:red;
position:relative;

animation:move 5s linear 2s infinite alternate;

}

@keyframes move{

0%{

background:red;
left:0;
top:0;

}

25%{

background:yellow;
left:200px;
top:0;

}

50%{

background:blue;
left:200px;
top:200px;

}

75%{

background:green;
left:0;
top:200px;

}

100%{

background:red;
left:0;
top:0;

}

}

</style>

</head>

<body>

<div></div>

</body>
</html>
```

### Output Path

```
Start

🟥

↓

🟨 → Right

↓

🟦 ↓ Down

↓

🟩 ← Left

↓

🟥 ↑ Up

Repeats Forever
```

# Animation Properties Summary

| Property                    | Purpose                  | Example                                                    |
| --------------------------- | ------------------------ | ---------------------------------------------------------- |
| `@keyframes`                | Defines animation steps  | `@keyframes move{}`                                        |
| `animation-name`            | Specifies animation name | `animation-name:move;`                                     |
| `animation-duration`        | Time for one cycle       | `5s`                                                       |
| `animation-delay`           | Wait before starting     | `2s`                                                       |
| `animation-iteration-count` | Number of repeats        | `3`, `infinite`                                            |
| `animation-direction`       | Direction                | `alternate`                                                |
| `animation-timing-function` | Speed                    | `linear`, `ease`                                           |
| `animation-fill-mode`       | Keeps final style        | `forwards`                                                 |
| `animation`                 | Shorthand property       | `animation:move 5s linear 2s infinite alternate forwards;` |

# Frequently Asked Interview Questions

### 1. What is CSS Animation?

CSS Animation is used to animate HTML elements without JavaScript.

### 2. What is `@keyframes`?

It defines the stages of an animation.

### 3. What is the difference between `from/to` and percentages?

* `from` = `0%`
* `to` = `100%`
* Percentages allow multiple intermediate stages.

### 4. What is `animation-duration`?

It specifies the time taken for one animation cycle.

### 5. What is `animation-delay`?

It specifies how long the animation waits before starting.

### 6. What is `animation-iteration-count`?

It specifies how many times the animation repeats.

### 7. What is `animation-direction`?

It specifies whether the animation moves forward, backward, or alternates.

### 8. What is `animation-timing-function`?

It controls the speed curve of the animation.

### 9. What is `animation-fill-mode`?

It controls whether the element keeps the first or last keyframe style.

### 10. What is the shorthand `animation` property?

It combines multiple animation properties into a single declaration.
